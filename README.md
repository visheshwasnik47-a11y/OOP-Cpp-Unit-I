# C++ Programming – Complete Notes

## 📚 About

This repository contains study notes on C++ programming, covering fundamental concepts of procedural and object-oriented programming. It is designed for engineering students and beginners preparing for exams.

## 📖 Topics Covered

### Unit 1: Introduction to C++

* Introduction to C++
* Procedural Programming vs Object-Oriented Programming
* Basic Data Types
* Derived Data Types
* Constants and Tokens
* Keywords, Identifiers and Variables
* Classes and Objects
* Structure vs Class
* Control Structures
* Arrays and Strings

### Unit 2: Functions and OOP Concepts

* Functions and Function Prototypes
* Function Calls and Utility Functions
* Constructors and Destructors
* Types of Constructors
* Objects and Memory Requirements
* Static Data Members and Member Functions
* Inline Functions
* Friend Functions

## 🎯 Objectives

* Understand the fundamentals of C++.
* Learn the concepts of object-oriented programming.
* Understand functions, classes and objects.
* Practise C++ programs with simple examples.
* Prepare for college examinations.
